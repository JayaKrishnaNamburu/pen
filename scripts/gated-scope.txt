# coverage:rules gated scope
# IDs covered by a named CI gate, not a test name. A bare ID is a
# parse error. Each row is five fields separated by " | ":
#   ID | gate | workflow | invoke | fingerprint
#
# coverage:rules accepts a row only after all of these hold:
#   - gate file exists (posix path, no "..")
#   - workflow is a .github/workflows/*.yml file that exists
#   - an uncommented `run:` or `command:` line contains invoke
#   - the gate file contains fingerprint
# Deleting the gate, unwiring it, or dropping the fingerprint fails
# the run. Do not list an ID here to shorten the unlisted report.
#
# Residual trust (what this does not check):
#   - the gate is not executed; a script that exits 0 on its own
#     failure path would still verify
#   - workflow triggers are not read (push-to-main-only is accepted)
#   - `continue-on-error` and matrix expressions are not parsed
# Register only gates you have watched fail, or that fail-close
# themselves on every green run (self-test / scratch mutation).
#
